## PHT Data Lake - Notebook 04: MapReduce batch jobs (Hadoop Streaming + Python, as in Lab 3)
Three overnight batch jobs over the **clean zone**, writing results to the **curated zone**:

| Job | Map emits | Reduce does | PHT problem |
|---|---|---|---|
| 1. Monthly sales | `branch|item|month -> qty, amount` | sums per key (the WordCount pattern) | monthly summary tables for reports |
| 2. Transfer matching | `from|to|item -> OUT/IN record` | **reduce-side join** of the two separate Tally entries of each transfer | transfers typed twice and never checked |
| 3. Stock reconciliation | `location|item -> opening / ±movement / closing` | opening + movements vs counted closing stock | stock records nobody can trust |

Run Notebooks 01 and 02 first. Scripts are saved in `/home/bigdata/PHT/mr`.

PARAGRAPH 4: 2b. Job 2 reducer - save transfer_reducer.py

%sh

cat > /home/bigdata/PHT/mr/transfer_reducer.py <<'EOF'
#!/usr/bin/env python3
# Job 2 reducer - all OUT and IN records of one route+item arrive together.
# pairs OUT with IN in 4 passes: same slip + same qty, same qty within 7 days, same slip, within 7 days
# status: MATCHED | QTY_MISMATCH | RECEIPT_MISSING | IN_TRANSIT (sent in the last 7 days) | RECEIPT_WITHOUT_DISPATCH
import sys, os
from datetime import datetime
DATA_END = datetime.strptime(os.environ.get("DATA_END", "2026-10-31"), "%Y-%m-%d")
WINDOW = 7

def d(s):
    return datetime.strptime(s, "%Y-%m-%d")

def emit(key, status, o, i, method):
    frm, to, item = key.split("|")
    out_date, out_q, out_v = (o[1], o[2], o[4]) if o else ("", "", "")
    in_date, in_q, in_v = (i[1], i[2], i[4]) if i else ("", "", "")
    lag = str((d(in_date) - d(out_date)).days) if (o and i) else ""
    print("\t".join([frm, to, item, status, out_date, in_date, str(out_q), str(in_q), lag, out_v, in_v, method]))

def match(key, recs):
    outs = sorted([r for r in recs if r[0] == "OUT"], key=lambda r: r[1])
    ins = sorted([r for r in recs if r[0] == "IN"], key=lambda r: r[1])
    used_in, done, pairs = set(), set(), []
    def in_window(o, r):
        return 0 <= (d(r[1]) - d(o[1])).days <= WINDOW
    # four passes, strictest first: slip+qty, date+qty, slip only, date only
    rules = [("SLIP", lambda o, r: o[3] and r[3] == o[3] and r[2] == o[2]),
             ("DATE", lambda o, r: in_window(o, r) and r[2] == o[2]),
             ("SLIP", lambda o, r: o[3] and r[3] == o[3]),
             ("DATE", lambda o, r: in_window(o, r))]
    for method, ok in rules:
        for j, o in enumerate(outs):
            if j in done:
                continue
            cands = [k for k, r in enumerate(ins) if k not in used_in and ok(o, r)]
            if cands:
                k = min(cands, key=lambda k: ins[k][1])
                used_in.add(k); done.add(j); pairs.append((o, ins[k], method))
    for j, o in enumerate(outs):
        if j not in done:
            pairs.append((o, None, ""))
    for o, i, method in pairs:
        if i is None:
            emit(key, "IN_TRANSIT" if (DATA_END - d(o[1])).days <= WINDOW else "RECEIPT_MISSING", o, None, "")
        else:
            emit(key, "MATCHED" if o[2] == i[2] else "QTY_MISMATCH", o, i, method)
    for k, r in enumerate(ins):
        if k not in used_in:
            emit(key, "RECEIPT_WITHOUT_DISPATCH", None, r, "")

cur, recs = None, []
for line in sys.stdin:
    p = line.rstrip("\n").split("\t")
    key, rec = p[0], (p[1], p[2], int(p[3]), p[4], p[5], p[6])   # direction, date, qty, slip, voucher, recorded_by
    if key != cur:
        if cur is not None:
            match(cur, recs)
        cur, recs = key, []
    recs.append(rec)
if cur is not None:
    match(cur, recs)
EOF
chmod +x /home/bigdata/PHT/mr/transfer_reducer.py
echo saved transfer_reducer.py

#!/usr/bin/env python3
# Job 3 - stock reconciliation: counted stock (godown summary) vs stock calculated from recorded movements
# reads 4 clean datasets at once; RECON_FROM / RECON_TO are snapshot dates passed with -cmdenv
# output: location|item_id <TAB> B|M|E <TAB> qty     (B = opening count, M = movement, E = closing count)
import sys, os
FROM = os.environ.get("RECON_FROM", "2026-08-31")
TO = os.environ.get("RECON_TO", "2026-10-31")
def inside(day):
    return FROM < day <= TO
def out(loc, item, tag, q):
    print("%s|%s\t%s\t%d" % (loc, item, tag, q))
for line in sys.stdin:
    f = line.rstrip("\n").split("\t")
    n = len(f)
    if n == 5:                                              # stock_snapshots: date, location, item, qty, value
        if f[2] and f[0] == FROM:
            out(f[1], f[2], "B", int(f[3]))
        elif f[2] and f[0] == TO:
            out(f[1], f[2], "E", int(f[3]))
    elif n >= 14 and f[8] in ("OUT", "IN", "WH_TO_SHJ1"):  # transfer_records
        if f[5] and inside(f[2]):
            q = int(f[9])
            if f[8] == "OUT":
                out(f[6], f[5], "M", -q)
            elif f[8] == "IN":
                out(f[7], f[5], "M", q)
            else:
                out("WH1", f[5], "M", -q); out("SHJ1", f[5], "M", q)
    elif n >= 17 and f[0].startswith("PUR/"):              # purchase_lines: booked into the warehouse on entry date
        if f[9] and inside(f[1]):
            out("WH1", f[9], "M", int(f[10]))
    elif n >= 17:                                          # sales_lines: stock leaves the branch (actual qty)
        if f[6] and inside(f[2]):
            out(f[0], f[6], "M", -int(f[7]))
EOF

#!/usr/bin/env python3
# Job 3 reducer - calculated = opening count + movements; compare with closing count
# output only the discrepancies: location, item, opening, movements, calculated, counted, difference
import sys
cur, b, m, e = None, 0, 0, 0
def out():
    calc = b + m
    if calc != e:
        loc, item = cur.split("|")
        print("%s\t%s\t%d\t%d\t%d\t%d\t%d" % (loc, item, b, m, calc, e, e - calc))
for line in sys.stdin:
    key, tag, q = line.rstrip("\n").split("\t")
    if key != cur:
        if cur is not None:
            out()
        cur, b, m, e = key, 0, 0, 0
    if tag == "B":
        b += int(q)
    elif tag == "E":
        e += int(q)
    else:
        m += int(q)
if cur is not None:
    out()
EOF

PARAGRAPH 14: Notes for the report
==============================================================================
%md
- **MapReduce beyond WordCount:** Job 1 *is* WordCount with a business key. Job 2 is a **reduce-side join**: the sender's and receiver's records come from two different Tally systems, and the shuffle brings both to the same reducer because they share the key `from|to|item`. Job 3 joins four datasets the same way.
- **Why MapReduce fits here:** these are large, simple overnight batch jobs where a few minutes don't matter.
- **Why MapReduce does NOT fit live stock:** each job starts new JVMs/containers and reads and writes HDFS between map and reduce, so even a small job takes tens of seconds (see the `real` time above). That's fine overnight, useless at the counter. Live stock uses Structured Streaming (Notebook 03).
- **Results for PHT:** every transfer is checked automatically. Missing receipts and wrong quantities, which nobody noticed in the two-voucher process, are listed for follow-up.
